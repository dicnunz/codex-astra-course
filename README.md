CODEX OPEN COURSE

# CODEX.00 | Codex with GPT-6 Astra

A complete open undergraduate course on using Codex with GPT-6 Astra, including the syllabus, calendar, readings, assignments, and 22 lecture handouts.

## Start Here

**You do not need to know Git, use a terminal, install anything, or have a GitHub account.**

1. [Download the complete course as a ZIP](https://github.com/dicnunz/codex-astra-course/archive/refs/heads/main.zip).
2. Open the downloaded ZIP file.
3. Open the `codex-astra-course-main` folder.
4. Double-click `index.html`.

The course will open in your web browser. From there, use the left-hand course navigation normally.

If you are already on the repository page, the same download is available through **Code -> Download ZIP**.

## What This Repository Is

A GitHub repository is simply a project folder with saved versions of its files. For this course, you can treat it like an ordinary folder. You do not need to understand branches, commits, pull requests, Actions, cloning, or Git to use it.

The files you are most likely to care about are:

| File | What it is |
| --- | --- |
| `index.html` | Course home page. Start here after downloading. |
| `syllabus.html` | Course description, requirements, and grading. |
| `calendar.html` | Session-by-session course schedule. |
| `readings.html` | Assigned OpenAI documentation and practitioner readings. |
| `lecture-handouts.html` | Index of all lecture handouts. |
| `assignments.html` | Writing assignments and guidelines. |
| `static_resources/` | The 22 lecture-handout PDFs. |

If you only want a lecture handout, open [`static_resources`](static_resources/) directly on GitHub and select any PDF. GitHub can display the PDFs in the browser without downloading the whole course.

## About the Course

This course treats Codex with GPT-6 Astra as an engineering system rather than a bag of prompts. It focuses on task specification, repository evidence, reasoning effort, durable instructions, skills and plugins, browser and computer tools, subagents, worktrees, long-context state, debugging, review, permissions, usage, and verifiable stopping conditions. Readings emphasize primary OpenAI documentation and first-hand writing from OpenAI practitioners, including Dominik Kundel and Jason Liu.
